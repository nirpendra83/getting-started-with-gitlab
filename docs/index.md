# Home

Welcome to the GitLab Getting Started guide. This project is designed to help you understand GitLab from both an administrator and a developer perspective.

## Goals of this guide

- Introduce the GitLab platform and common concepts
- Explain how GitLab administrators configure projects, users, and permissions
- Cover the CI/CD model used by GitLab pipelines
- Provide examples you can adapt for real-world workloads

## What you will learn

- How GitLab organizes repositories, groups, and users
- How to install and configure GitLab and GitLab Runner
- How pipelines, jobs, and stages work
- How to secure and maintain your GitLab instance
- How to deploy applications with GitLab CI/CD and Kubernetes

## Recommended reading order

1. Admin overview
2. Installation and setup
3. Users, groups, and permissions
4. CI/CD fundamentals
5. Runner setup
6. Best practices and troubleshooting

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
mkdocs serve
```

This material is intended as a starter guide for GitLab onboarding and DevOps training.
