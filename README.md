# Getting Started with GitLab

This repository contains training materials and a hands-on guide for GitLab administration and GitLab CI/CD workflows. It uses MkDocs with the Material theme and is designed for modern onboarding and training.

## Contents

- docs/ — documentation source
- examples/ — sample GitLab CI/CD pipeline files
- .github/workflows/ — automation to build and publish the docs site

## Quick start

1. Read the docs in the `docs/` folder.
2. Review the example CI files under `examples/`.
3. Customize the content and pipelines for your environment.

## Local preview

```bash
python -m pip install -r requirements.txt
mkdocs serve
```
